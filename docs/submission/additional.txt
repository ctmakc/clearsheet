Scaling: one MI300X (192 GB) holds Gemma 3 27B in bf16 with room to batch; our benchmark reached 1118 output tokens/s at 64 parallel requests, about 80 discharge summaries per minute for the extraction step. A translated sheet (extract + explain + back-check) is about 2,400 output tokens, roughly 2 GPU-seconds at that rate (about $0.001 at $1.99 per MI300X-hour). A hospital can run it on its own AMD GPU so that only masked text ever reaches the model. The hosted demo replays responses recorded live on the MI300X (AMD AI Notebooks pod) because the GPU session is time-limited; set CLEARSHEET_BASE_URL to any vLLM / OpenAI-compatible endpoint to run it live. All cases are synthetic. The checks and the eval are in the repo (pytest, eval/run_eval.py, eval/bench.py).
